# Brand tokens

Generated by `scripts/generate_tokens.py` from `Logo/Official Logo.jpg`. Do not edit by hand.

## Logo analysis

The logo is a 3D circular badge: red background, cream/white ring and letter **J**, near-black inner disc and a bright red swoosh. Colours were sampled with `scripts/extract_palette.py` (Pillow, median of a 9x9 block per region):

| Region | Sampled colour |
| --- | --- |
| Swoosh (bright red) | `#DB0100` |
| Background (gradient, light to dark) | `#C5281F` to `#821210` |
| Inner disc | `#1C0807` |
| Ring and letter J (cream) | `#E9E3D7` / `#F0E8DD` (dominant `#EBE5DB`) |

Rules: logo colours are never altered. Only neutrals, the hover shade, the soft tint and status colours were chosen, and each text pair is verified for WCAG AA below.
